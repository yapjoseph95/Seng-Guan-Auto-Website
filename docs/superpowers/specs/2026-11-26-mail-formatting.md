# Mail formatting
User request: Settings dropdown consolidates Signatures and Notifications; company-logo email headers; bold, italic, alignment and font size in message/signature; signature image upload.
Implementation choices: Tiptap shared editor (undo and selection handling); additive HTML in saved drafts and delivery with text alternative; mailbox-specific HTML signature/header settings, preserving existing plain signatures. Public, unguessable raster branding image URLs in private R2 bucket via a dedicated image-only GET route. Server parses and allowlists HTML/styles/image URLs. Existing upload attachments stay private and separate. Header is configurable, with company-logo insertion available. Incoming remote images remain blocked; only own branding images render in sandboxed mail previews.
